市政饮用水污染响应

使用 JSON API 创建污染事件、登记水源或管网记录，并完成复检、通知、冲洗、消毒和恢复。请求头 X-User-Id/X-Role/X-Region 标识身份与所在区域。

GET  /health
GET  /api/state
GET  /api/items
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions
POST /api/incidents/link            # 跨区配对：两区立案接成同一件污染事件（监管角色）
POST /api/reconciliation/batches    # 断网补录：按 seq 回放，区域+外部编号只入账一次
GET  /api/reconciliation/pending    # 版本对不上等待处理的补录（普通角色限本区域）

配对后同一通知编号在联动区只发一次；任一联动区复检未全部达标则挡住恢复并列出缺哪个区；补录审计事件带 _origin.kind=backfill；监管角色可跨区处置，普通角色访问外区记录返回 403。
